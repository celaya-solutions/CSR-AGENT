## 2026.9.4

First OpenAgent release by Celaya Solutions, a course edition derived from OpenClaw 2026.9.4. Upstream release history is not carried forward; see NOTICE.md for attribution.

### Changes

- Trim the bundled plugin set to the course plugins: acpx, agent-workforce, anthropic, browser, codex, device-pair, discord, document-extract, duckduckgo, image-generation-core, llama-cpp, llm-task, memory-core, ollama, openai, openrouter, telegram, and web-readability.
- Remove the native macOS, iOS, Android, and Linux apps and the QA lab.
- Stop contacting hosted OpenClaw services by default: telemetry, the plugin registry, hosted plugin and model catalogs, and the iOS push relay each need an operator-configured URL.
- Install from source only.
