# Zero to Agent Amazon Bedrock Provider

Official Zero to Agent provider plugin for Amazon Bedrock. It adds Bedrock model discovery, text generation, embeddings, and guardrail-aware provider routing for agents that use AWS-hosted models.

Install from Zero to Agent:

```bash
openclaw plugins install @openclaw/amazon-bedrock-provider
```

Configure AWS credentials and region through your normal Zero to Agent credential/profile setup, then select Bedrock models with the `amazon-bedrock/...` provider prefix.
