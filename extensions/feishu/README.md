# Zero to Agent Feishu/Lark

Official Zero to Agent channel plugin for Feishu and Lark workplace chats. Community maintained by @m1heng.

Install from Zero to Agent:

```bash
openclaw plugins install @openclaw/feishu
```

Configure the Feishu/Lark app credentials in Zero to Agent, then connect the plugin to the chats where agents should receive and send messages.
